# sahtTatva — Hybrid AI–NWP Multi-Model Forecast Blending System

**Smart India Hackathon 2026 · Problem Statement SIH26081**
**Ministry of Earth Sciences (MoES) · Software category**

sahtTatva blends forecasts from three operational global NWP models —
**GFS (NOAA), ICON (DWD) and GEM (Environment Canada)** — into one optimized
forecast for **any location in Uttar Pradesh**.
